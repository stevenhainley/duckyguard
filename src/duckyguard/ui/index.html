    Keyboards that type too fast get stopped
    
    
      
      
    • A USB device can claim to be a keyboard and type a command in under a second. DuckyGuard times every key and blocks typing no hand could produce.
      • 
      
    • A keyboard you have not trusted is held the moment it appears: nothing it types gets through until you choose.
      • 
      
    • When it blocks something, it saves the text of that burst on this Mac so you can see what was attempted. Nothing is sent anywhere. It is not an antivirus, and a device that imitates a hand well enough can still get through.
