DuckyGuard.
Starting

Keyboards that type too fast get stopped.

A USB stick can pretend to be a keyboard and type a command in under a second (Rubber Ducky, Flipper Zero, O.MG cable). DuckyGuard watches the rhythm of every keystroke. When a burst is faster and more even than any hand, it drops the rest of the keys before they reach an app.

  • What it does: blocks machine-timed bursts, tells you why in plain English, remembers keyboards you trust.
  • What it does not do: stop slow, randomised payloads; stop the first few keys of a burst; replace an antivirus.
  • Privacy: nothing leaves this Mac. Incidents live in a folder only you can read.

Two permissions.

macOS asks you to allow apps that watch or change keystrokes. Both are read in System Settings, Privacy & Security. DuckyGuard checks every two seconds, so just come back here.

Input Monitoring Lets DuckyGuard see keystrokes system-wide so it can time them.
Accessibility Lets DuckyGuard drop keystrokes. Without it DuckyGuard can only warn.

In the list that opens, turn on DuckyGuard (or the app you launched it from). If it is not listed, click + and pick it.

See it work, safely.

DuckyGuard can type a harmless sentence into its own window at machine speed. You will see the first keys land, the shield turn red, and the rest get dropped. No hardware, nothing runs.
